# New Chronicles

> Et samlet, publiceret arkiv af tekster til flere D&D-kampagner: baggrundshistorier, lore, session-noter, epiloger og mere.

> **Status i Paperclip:** `in_progress` · **Repo:** [github.com/qvisty/new_chronicles](https://github.com/qvisty/new_chronicles) · **Live:** [qvisty.github.io/new_chronicles](https://qvisty.github.io/new_chronicles/) · Del af ClipCores portefølje af personlige indholdsprojekter.

---

## Formål og vision

Formålet er at samle og bevare alt skriftligt materiale til ejerens Dungeons & Dragons-kampagner ét sted og gøre det tilgængeligt som en pæn, læsbar hjemmeside. I stedet for spredte Word-filer bliver kampagne-lore, karakter-baggrunde, epiloger og session-noter til et samlet, søgbart arkiv, der publiceres via GitHub Pages.

Visionen er et levende kampagne-arkiv, der er let at læse, dele og udvide, efterhånden som kampagnerne skrider frem.

## Slutmål (Definition of Done)

- Alt kampagne-materiale samlet i repoet og publiceret pænt via GitHub Pages.
- En struktur, hvor nyt indhold let kan tilføjes og automatisk kommer online.

## Nuværende status

- **Fase:** Drift / løbende udbygning
- **Prioritet:** medium
- **Hvor langt er vi:** Repoet indeholder et stort materiale (800+ filer), bl.a. kampagnen "Chains of the Ancients" med lore-dokument, karakter-baggrundshistorier, epiloger, historier og session-noter. Siden bygges og udgives automatisk til GitHub Pages via en workflow ([`.github/workflows/deploy.yml`](https://github.com/qvisty/new_chronicles/blob/main/.github/workflows/deploy.yml)) og er live på [qvisty.github.io/new_chronicles](https://qvisty.github.io/new_chronicles/).
- **Seneste milepæl:** Stort indholdsarkiv samlet og publiceret via GitHub Pages.

## Planlægning og faser

- ✅ **Fase 1 — Indsamling:** Kampagne-tekster samlet i repoet.
- ✅ **Fase 2 — Publicering:** Automatisk build/deploy til GitHub Pages.
- 🔧 **Fase 3 — Struktur & læsbarhed:** Løbende organisering og forbedring af navigation/præsentation.
- ⬜ **Fase 4 — Udbygning:** Tilføj nyt materiale, efterhånden som kampagnerne udvikler sig.

## Mangler på kort sigt (næste skridt)

- [ ] Forbedr navigation/oversigt på den publicerede side (indholdsfortegnelse pr. kampagne).
- [ ] Ryd op i mappe-/filstruktur for konsistens.
- [ ] Sikr at alle filer renderes korrekt på Pages.

## Mangler på lang sigt (roadmap)

- [ ] Understøt flere kampagner i en klar, ensartet struktur.
- [ ] Evt. søgning på tværs af arkivet.
- [ ] Løbende vedligehold, når nyt materiale kommer til.

## Teknik og opsætning

- **Indhold:** Markdown-filer organiseret pr. kampagne.
- **Publicering:** GitHub Pages via GitHub Actions-workflow (`.github/workflows/deploy.yml`).
- Nyt indhold committes til `main` og udgives automatisk til Pages.
